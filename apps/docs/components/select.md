# select

A dropdown. Click to open, then pick an option. Options come from
`options="A, B, C"` (`items="…"` works too). Aliases: `dropdown`, `combo`,
`menu`.

```grafiq
select "Choose a theme" options="Light, Dark, System, High contrast"
```

It also works well as an action menu:

```grafiq
select "Actions" options="Rename, Duplicate, Delete"
```
